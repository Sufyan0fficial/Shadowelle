# Product Overview

## What is Dawn

Dawn is Shopify's official reference theme: an HTML-first, JavaScript-only-as-needed e-commerce storefront built around performance, accessibility, and Online Store 2.0.

This repository is the clean starting point for a new custom Shopify storefront based on the Dawn theme.

## Core Philosophy

- **Web-native first:** Use modern browser capabilities through progressive enhancement.
- **Performance-focused:** Prefer server-rendered HTML through Liquid and minimal client-side JavaScript.
- **Online Store 2.0:** Use sections, blocks, JSON templates, and theme editor settings correctly.
- **Merchant-ready:** Build production-quality storefront components that merchants can configure in Shopify admin.
- **Accessible by default:** Preserve semantic HTML, keyboard navigation, focus states, and useful screen-reader labels.

## Target Use Cases

- Starting point for custom Shopify theme development
- Reference implementation for Shopify theme best practices
- Flexible storefront sections that can be managed through the theme editor
- E-commerce experiences that prioritize performance, accessibility, and maintainability
